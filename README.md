# מהתלונה לתובנה

האתר המלווה ליום העיון "שירות לתושב" של תוכנית צוערים לשלטון המקומי, בעיריית דימונה, ביום ראשון 15.11.2026.

- `index.html`: האתר עצמו. קובץ אחד, בלי בנייה. כולל לו"ז חי לפי שעון ישראל, הגעה, דוברים, קבוצות וסרטון.
- `branding/moods.html`: ארבעת כיווני האווירה. הכיוון שנבחר הוא "חול ושמש".

לפרסום ב-GitHub Pages: Settings → Pages → Deploy from a branch → `main`, תיקיית השורש.
