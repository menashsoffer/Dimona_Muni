# מהתלונה לתובנה

האתר המלווה ליום העיון "שירות לתושב" של תוכנית צוערים לשלטון המקומי, בעיריית דימונה, ביום ראשון 15.11.2026.

## מבנה

אתר סטטי בלי שלב בנייה. כל עמוד הוא קובץ HTML קטן, והתוכן, העיצוב וההתנהגות מופרדים:

```
index.html            עמוד הבית: עכשיו, לו"ז, הגעה, אנשים, קבוצות, הכירו את דימונה
quiz.html             החידון "מכירים את דימונה?"
css/site.css          העיצוב המשותף: צבעים, כותרת עליונה, ניווט, כרטיסים, כפתורים
css/home.css          עיצוב עמוד הבית
css/quiz.css          עיצוב החידון
js/site.js            הניווט (רשימת PAGES) ואפקטי הגלילה, משותף לכל העמודים
js/home.js            הלו"ז החי לפי שעון ישראל, כרטיסי האנשים והקבוצות
js/quiz.js            מנוע החידון
js/content/event.js   תאריך היום והלו"ז
js/content/people.js  האנשים והקבוצות
js/content/quiz.js    שאלות החידון, כל אחת עם המקורות שלה
assets/               לוגואים ותמונות (assets/people/<שם>.png)
branding/moods.html   ארבעת כיווני האווירה. הכיוון שנבחר הוא "חול ושמש"
tools/artifact-page.py  מכין את index.html לפרסום כ-Artifact ב-claude.ai
```

## איך מוסיפים דברים

- **לעדכן תוכן** (שעה, שם, תמונה, תיאור פרויקט): רק בקבצים שב-`js/content/`. אין צורך לגעת ב-HTML.
- **להוסיף שאלה לחידון**: רשומה חדשה ב-`js/content/quiz.js`, רק עם מקור שכותב את התשובה במפורש.
- **להוסיף עמוד או פיצ'ר**: מעתיקים את `quiz.html` כבסיס, יוצרים לו קובץ CSS ו-JS משלו, ומוסיפים שורה אחת ל-`PAGES` ב-`js/site.js` כדי שיופיע בניווט בכל העמודים.

## צפייה ופרסום

- הקבצים משתמשים ב-ES modules, ולכן פתיחה בלחיצה כפולה לא תעבוד. לצפייה מקומית: `python3 -m http.server` ואז http://localhost:8000.
- לפרסום ב-GitHub Pages: Settings → Pages → Deploy from a branch → `main`, תיקיית השורש.
